# Demo

Two small atmospheric rooms built with Motion Engine:

- **Prism Hall** is a walkable 3D stone room with three portal arches, colored
  point lights, and animated portal and post-processing shaders.
- **Echo Room** is a 2D architectural companion with three arches, glowing
  light pools, and the same shifting shader treatment.

Press **Tab** to move between rooms. In Prism Hall, use **WASD** to walk,
**mouse** to look, and **Shift** to run. The 2D room is a still, illustrative
view.

Run from the repository root with:

```powershell
python -m emoeng run emoeng\projects\demo
```

Or open the project in the editor and press **F5**.
